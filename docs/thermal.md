# 83SH 散热实测：转速 / 负载 / 温度的关系

实测日期 2026-11-24，机型 小新 Pro 14 GT（83SH），Ultra X7 358H，性能档（ITS=3），
Windows 高性能电源计划，交流供电，室温约 26–27 ℃。

数据目录 `thermal/`，原始采样 3 秒一次，每格稳态取末尾 30 秒均值。

## 结论

| 问题 | 答案 |
|---|---|
| 满载把 CPU 压在 90 ℃ 需要多少转 | **约 2200 rpm** |
| 满载把 CPU 压在 80 ℃ 需要多少转 | **约 3260 rpm** |
| 70% 占用率压在 90 ℃ | **约 1900 rpm** |
| 70% 占用率压在 80 ℃ | **约 2730 rpm** |
| 1500 转下多少负载到 90 ℃ | **约 48%**（约 33 W） |
| 2000 转下多少负载到 90 ℃ | **约 65%**（约 38 W） |
| 2500 / 3000 / 3500 转能否到 90 ℃ | **不能**，满载上限分别只有 86 / 82 / 78 ℃ |

## 三个反直觉的发现

**1. 占用率降一半，功耗只降一成。**
70% 占空比时封装功耗 36–39 W，满载是 40–43 W。线程数减少后 CPU 会自动拉高频率补齐，
功耗几乎贴着 PL1（约 38–43 W）不松口。**所以「70% 负载」并不会让机器凉下来多少，
只低 4~5 ℃。**

**2. 温度几乎只由转速决定。**
因为功耗恒定，稳态温度 ≈ 环境温度 + R(转速) × 功耗。实测热阻：
6000 转 1.03 ℃/W、4500 转 1.14、3500 转 1.27、3000 转 1.34、2500 转 1.45、2100 转 1.54、2000 转 1.61。
从 2000 提到 3000 转，热阻降 17%；从 3000 提到 6000 转，热阻再降 23%。
**边际收益衰减很快，3000–3500 转是性价比拐点。**

**3. 2000 转是悬崖。**
2000 转满载稳态 95.8 ℃，已经贴近 TjMax 100 ℃；1900 转以下满载直接顶到 96 ℃ 以上。
风扇 1 的出厂下限是 2000 rpm、风扇 2 是 2300 rpm——低于这个值 EC 也会运转，
但风量已经不足以带走 40 W，CPU 只能靠降频自保。

## 测量方法

`tools/thermal.ps1` + `tools/loadgen.exe`。

- 负载：原生多线程忙等，100 ms 周期内按占空比忙等 / 睡眠，`timeBeginPeriod(1)` 保证精度
- 温度：PawnIO 驱动执行 `RDMSR 0x1B1`（封装 DTS），TjMax 由 `0x1A2` 读出
- 功耗：RAPL `0x611` 能量计数器差分，单位取自 `0x606`
- 转速：WMI `LENOVO_OTHER_METHOD.SetFeatureValue`，两只风扇同写
- 每格先空转 10 秒等转速到位，再加载 150 秒，末尾 30 秒取均值
- 安全阈值 94–97 ℃，超温立刻停负载并写 0 交还 EC

## 误差与偏差

- **热浸**：整机连续跑 1.5 小时后机壳已热透。同为 3000 转满载，冷机 76.0 ℃、热机 82.2 ℃，
  差 6 ℃。表中用的是热机值（更接近日常长时间使用），冷机开机会低 5~6 ℃。
- **采样窗口**：每格 150 秒，多数点 30 秒漂移 ≤1 ℃；1500 转 30/50% 两格仍在缓升（漂移 2–3 ℃），
  真实稳态略高于表中值。
- **环境温度**只做了估计（26–27 ℃），未用独立温度计校准。
- 3500 转满载复测 77.1 → 78.9 ℃，重复性约 ±1 ℃。
- 低于 1900 转的几格是「超温中止」，只说明稳态高于 96 ℃，具体数值未测。
